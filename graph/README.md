# hopr-network-graph

Implementation of the HOPR network graph

Part of the [HOPR](https://hoprnet.org/) protocol implementation.

## Logging

Routine graph observation updates and their spans are emitted at TRACE. Enable TRACE in a build that retains it when investigating
individual observations. Exceptional attribution and rejected-report diagnostics retain their existing levels. This changes no graph APIs or
path selection behavior.
